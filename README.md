# 🤖 SubTracker Bot

**SubTracker** — это удобный Telegram-бот для учета платных подписок и регулярных расходов. Бот вовремя напомнит о грядущем списании, покажет статистику трат и поможет не потерять деньги на забытых сервисах.

## 🌟 Основной функционал

* **Бесшовный интерфейс (App-like):** Бот не засоряет историю чата, а плавно обновляет одно главное сообщение (inline-меню).
* **Умные напоминания:** Фоновый планировщик ежедневно проверяет базу и присылает алерты о списаниях.
* **Категории трат:** Кино, Музыка, Игры, Работа, Спорт и др.
* **Детальная статистика:** Подсчет общих расходов, выявление самой дорогой подписки и построение наглядных ASCII прогресс-баров по категориям.
* **Персонализация профиля:** 
  * Выбор базовой валюты (₽, $, €, ₸).
  * Настройка времени отправки уведомлений (например, в 10:00 или 19:00).
  * Выбор срока напоминания (в день списания, за 1 или за 3 дня).

## 🛠 Технологии

* **Python 3.9+**
* **Aiogram 3.x** — асинхронный фреймворк для Telegram API.
* **Aiosqlite** — асинхронная работа с базой данных SQLite.
* **APScheduler** — продвинутый планировщик фоновых задач.
